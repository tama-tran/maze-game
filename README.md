# maze-game
A simple maze game I created while taking the Code In Place 2026 course.

It's a maze game where players use the keyboard to move a character around the canvas. There are four keys available (`A`, `S`, `D`, `W`), each corresponding to a different direction. The goal is to find the exit without hitting the walls.

## How to Play
1. Run the program and click `1` or `2` to choose a maze.
2. Find your character (the orange circle at the bottom-left, marked "You're here!").
3. Move it to the exit (the red triangle at the top-right) using the keys below.

| Key | Direction |
|-----|-----------|
| `W` | Up        |
| `A` | Left      |
| `S` | Down      |
| `D` | Right     |

## Requirements
- Python 3
- The `graphics` library provided by the **Code in Place** course.
